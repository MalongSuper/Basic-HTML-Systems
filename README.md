# Basic HTML Systems

A collection of small, self-contained web systems built with **HTML, CSS, and JavaScript**. The repository contains basic applications, experiments, utilities, and interactive systems, with most projects implemented as a **single HTML file**.

Many of the systems are **vibe coded**, using AI-assisted development to quickly explore ideas, build prototypes, and experiment with different web interactions and designs.

## Contents

* Basic web applications
* Interactive utilities
* Small games and experiments
* UI and design experiments
* JavaScript-based systems
* Single-file HTML projects
* AI-assisted and vibe-coded projects

## Structure

Most projects are intentionally kept simple:

```text
project/
└── index.html
```

The HTML file may contain the **HTML structure, CSS styling, and JavaScript logic** in one place, making each project easy to open, test, and share.

## Purpose

This repository serves as a collection of practical HTML experiments and small systems rather than a collection of large production applications.

The projects are useful for exploring:

* HTML structure
* CSS styling
* JavaScript interactions
* Browser APIs
* User interfaces
* Rapid prototyping
* AI-assisted coding

## Notes

Because many projects are experimental or vibe coded, the code structure and complexity may vary between projects. Some systems are primarily created for learning, experimentation, or demonstrating an idea rather than production use.

## Running a System

For most projects, simply open the `.html` file in a modern web browser.

```text
Open → index.html → Run in browser
```

Some projects may require a local server if they use browser features that restrict direct file access.
